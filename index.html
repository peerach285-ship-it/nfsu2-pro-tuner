About this build

NFSU2 PRO TUNER · 0.2.0

รุ่น iPhone ออกแบบเป็นเว็บแอป (PWA) ใช้หน้าจอสัมผัสและพื้นที่จัดเก็บในเครื่อง ไม่ต้องติดตั้ง Chrome Extension

ข้อจำกัดสำคัญ
รุ่นนี้สร้างและจัดการโปรไฟล์จูนเท่านั้น ยังไม่แก้ค่าภายในเกมโดยตรง การเปลี่ยน HP/ECU/Turbo ในหน้านี้ไม่ได้ทำให้เกมเปลี่ยนสมรรถนะเอง การเชื่อมเกม NFSU2.xyz ต้องพัฒนาและทดสอบตัวเชื่อมแยกต่างหาก

ติดตั้งบนหน้าจอ iPhone

  1. เปิดเว็บแอปนี้ผ่าน Orion
  2. แตะเมนู Share หรือเมนูของเบราว์เซอร์
  3. เลือก Add to Home Screen หากมีให้ใช้งาน
  4. เปิดจากไอคอน NFSU2 PRO TUNER
